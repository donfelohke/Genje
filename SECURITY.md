# GENJE Security and Privacy

Report security issues privately through the contact route on the maintainer's GitHub profile or repository owner page. Include the affected component, impact, and reproduction steps; do not publish secrets or private participant information.

Never commit access tokens, passwords, private keys, private contact lists, unreleased sensitive recordings, or participant data without an approved basis and consent. Redact logs and metadata before publication. Rotate exposed credentials and assess any affected systems.

For movement, performance, or participant data, document consent, purpose, access, retention, and deletion expectations before collection. Do not turn embodied practice into covert monitoring, person-scoring, diagnosis, or hidden profiling.

This policy does not assert that automated security scanning or branch protection is enabled.
