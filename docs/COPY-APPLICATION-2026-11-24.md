# GENJE — Creative and Campaign Copy Guide

**Domain:** EXPRESSION.  
**Identity:** GENJE ZA WARENA — THE FIRE OF THE FORMIDABLE.

## Position

GENJE is the embodied creative expression in the FELOH practice: Genge-rooted sound and aesthetics, AfroTech, livecoding, audiovisual experimentation, movement, choreography, choreohacking and livity.

GENJE is an independent creative practice—not a WARENA product, company, checkout or booking surface. **ONLY NAKEBUSEN TRANSACTS.**

“The Fire of the Formidable” is an authored creative interpretation, not a universal translation or established etymology. Keep Sheng meanings contextual and attributed.

## Core copy

**Short:** GENJE connects Genge-rooted sound, code, movement and visual experimentation through human-authored creative practice.

**Long:** GENJE explores the relationship between rhythm, movement, sound, code and cultural expression. Its practice includes livecoding, audiovisual performance, algorithmic improvisation, choreography and choreohacking. Computation is a medium; it does not replace the human creator or reduce culture to generic data.

## Design copy

Visual language should be rhythmically alive and culturally situated: strong editorial hierarchy, deliberate negative space, tactile material cues, considered typography and intentional motion. Keep the creator and the work central.

Avoid generic luxury templates, forced slang, default Rasta shorthand, unsupported cultural symbolism, neon-AI haze, decorative code clutter and collage without compositional logic.

Use the shared FELOH palette and type references, but allow GENJE work to develop its own art direction within the common identity.

## Rights, provenance and evidence

Record creator, collaborators, performers, source samples, licences, consent, image/audio rights, context and publication approval. Distinguish concept, rehearsal, research, performance, recording and released work. A project README or visual prompt does not prove that an event or performance occurred.
